# 📊 iPhone Sales Data Analysis using Python

This project performs an exploratory data analysis (EDA) on iPhone sales data to understand sales patterns, customer preferences, and revenue trends.
The analysis is done using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn.

## 📁 Dataset

The dataset contains sales information of different iPhone models including:
- Product Name
- Brand
- RAM
- UPC Code
- Original Price
- Discount Percentage
- Final Price
- Rating
- Reviews Count
- Quantity Sold
- City
- Order Date

A new **Revenue column** was created during analysis.

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Data Analysis Performed
The following analysis was performed on the dataset:

### 1️⃣ Top Selling iPhone Models
Identified which iPhone models sold the most units.

### 2️⃣ Revenue by City
Analyzed which cities generated the highest revenue.

### 3️⃣ Rating vs Quantity Sold
Examined the relationship between product ratings and sales performance.

### 4️⃣ Discount vs Quantity Sold
Analyzed how discounts impact the number of units sold.

### 5️⃣ Monthly Revenue Trend
Visualized how revenue changes over time.

### 6️⃣ Correlation Heatmap
Used a heatmap to analyze relationships between numerical variables such as price, discount, quantity sold, and revenue.

## 📈 Key Insights

- Higher-rated products tend to have better sales performance.
- Discounts positively impact sales volume.
- Some cities contribute significantly more revenue than others.
- Revenue trends change over time depending on pricing and demand.
